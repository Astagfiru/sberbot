# Анализатор отзывов отделений Сбера

![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)
![Flask](https://img.shields.io/badge/Flask-2.0+-green.svg)
![GigaChat](https://img.shields.io/badge/GigaChat-API-yellow.svg)

Веб-приложение для анализа отзывов о банковских отделениях Сбера с платформы Яндекс.Карты с использованием искусственного интеллекта GigaChat.

## Возможности

- 📊 Анализ отзывов по различным временным периодам
- 📈 Визуализация статистики оценок (графики и диаграммы)
- 🤖 Автоматический анализ тональности и выявление проблем с помощью GigaChat
- 🏦 Поддержка множества банковских отделений по разным городам
- 🔍 Фильтрация отзывов по дате

## Использование

1. Выберите город из списка
2. Выберите отделение банка
3. Укажите период для анализа (последние 24 часа, месяц, год или произвольный интервал)
4. Нажмите "Анализировать"

Приложение:
- Соберет отзывы с Яндекс.Карт
- Построит графики распределения оценок
- Сгенерирует аналитический отчет с помощью GigaChat
- Покажет список всех отзывов за выбранный период

## Технологии

- **Backend**: Python, Flask
- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Аналитика**: GigaChat API, Matplotlib
- **Парсинг**: Selenium, yandex-reviews-parser
